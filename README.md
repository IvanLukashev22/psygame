# PSYGAME

Лендинг авторских трансформационных игр Анны Орловой.

## Запуск

```bash
npm start
```

Откроется `http://127.0.0.1:5173` (или `PORT` из окружения).

## Документация

| Файл | Зачем |
|------|--------|
| [AGENTS.md](./AGENTS.md) | Контекст для AI: стек, правила правок |
| [STRUCTURE.md](./STRUCTURE.md) | Карта файлов, секций, якорей, JS |
| [DESIGN.md](./DESIGN.md) | Дизайн-система (цвета, типографика, компоненты) |

## Главный файл

Правки UI и логики — в **`index.html`**.
